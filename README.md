# how

야간매출 계산기 — 현재매출에서 주간매출을 빼서 야간매출을 구하고, 날짜별로 기록합니다.

- 웹앱: https://definek.github.io/how/
- 서버·DB 없이 HTML 한 파일로 동작하며, 기록은 브라우저 저장소에 JSON으로 보관합니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (HTML + CSS + Vanilla JS) |
| `data/sample.json` | 예시 기록 5건. 앱의 `불러오기` 버튼으로 그대로 가져올 수 있습니다. |

## 기능

- `야간매출 = 현재매출 − 주간매출` 자동 계산 (입력 즉시 반영)
- 두 입력값과 날짜를 자동 저장 — 새로고침해도 유지
- 입력칸별 `다시` 버튼, 날짜 `오늘` / `어제` 빠른 선택
- 기록 저장 · 수정 · 삭제, 날짜순 목록과 야간매출 합계
- `JSON 내보내기` / `불러오기`로 기기 간 백업 · 복원

## 데이터 형식

브라우저 저장소(`localStorage`)의 `weekly-sales-calculator` 키에 아래 형태로 저장되고,
`JSON 내보내기`도 같은 `records` 구조를 사용합니다.

```json
{
  "version": 2,
  "draft": { "date": "2026-08-15", "weekly": 0, "current": 0 },
  "records": [
    {
      "id": "sample-2026-08-14",
      "date": "2026-08-14",
      "weekly": 900000,
      "current": 1320000,
      "savedAt": "2026-08-14T22:10:00.000Z"
    }
  ]
}
```

| 필드 | 설명 |
| --- | --- |
| `date` | 기록 날짜 (`YYYY-MM-DD`) |
| `current` | 현재매출 (입력값) |
| `weekly` | 주간매출 (입력값) |
| `savedAt` | 마지막으로 저장한 시각 |

야간매출은 저장하지 않고 `current - weekly`로 그때그때 계산합니다.
`draft`는 아직 기록으로 저장하지 않은 입력칸 상태입니다.

구버전(`version: 1`)은 야간매출을 입력받아 `{ night, current }`로 저장했습니다.
지금 앱은 이를 읽을 때 두 금액이 그대로 유지되도록 `weekly = current - night`로 환산해
새 형식으로 다시 저장합니다.

## 샘플 데이터 사용법

1. [`data/sample.json`](data/sample.json)을 내려받습니다.
2. 앱에서 `불러오기` → 내려받은 파일 선택.
3. 기존 기록이 있으면 교체 여부를 먼저 확인합니다.
